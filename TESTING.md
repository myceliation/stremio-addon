# Mycelium: order of operations

Open the Watchlist server window → **🍄 Online version (Mycelium)…** (or double-click `mycelium.pyw`).

1. **Put online** — whenever the code here changes (the Status line turns amber when it has).
2. **Make my copy** — done once; the link is saved.
3. **Add to Stremio** — installs/updates Mycelium + Watch History at the top of your add-ons.
4. **Sync my history** — approve once; from then on whatever you finish in Stremio joins Watched by itself.
5. **Check it works** — Yes = full stress test on a temporary copy with every option on (~10 min);
   No = quick check of your own copy (~1 min).
6. **Copy my library** — the Watchlist server's library, watched/blacklist, history and ratings. Preview first.
   The Watchlist server keeps its own data.
7. **Publish** — lists both add-ons in Stremio's Community catalog, then publishes this folder to
   github.com/myceliation/stremio-addon and sends the Stremio bug fixes as pull requests.
