  LAUNCHING — QUICKEST WAYS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  NO CMD WINDOW (silent background, recommended):
    Double-click:  start_servers.vbs
    → Kills any old instances on 7000/7001, starts both servers,
      then opens http://localhost:7001 in your browser.

  WITH CMD WINDOW (you see log output):
    Double-click:  start_servers.bat
    → Same thing but keeps a console showing "Servers started."

  STOP EVERYTHING:
    Double-click:  stop_servers.bat
    → Kills whatever is on ports 7000 and 7001.

  COMMON PROBLEMS & FIXES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  "Address already in use" / port conflict:
    → Run stop_servers.bat, wait 5 seconds, start again.
    → Or kill manually:
        for /f "tokens=5" %a in ('netstat -aon ^| findstr ":7000 "') do taskkill /f /pid %a
        for /f "tokens=5" %a in ('netstat -aon ^| findstr ":7001 "') do taskkill /f /pid %a

  Sync to Stremio Library button does nothing / returns error:
    → Stremio must be open (it runs the local server on 11470)
    → Confirm: curl http://127.0.0.1:11470/api/addonCollectionGet
    → If that fails, open Stremio and wait ~10 seconds, try again

  Add-on not showing in Stremio catalog:
    → Stremio → Add-ons → paste: http://localhost:7000/<uuid>/manifest.json
    → Check add-on is running: curl http://localhost:7000/manifest.json
    → Restart add-on if needed (stop_servers.bat → start_servers.vbs)

  Import got junk entries (UI text, non-films):
    → Go to http://localhost:7001 → Library tab
    → Select junk items and delete them
    → Or in sqlite3:
        DELETE FROM watchlist WHERE title IN ('Text','Standard','Appearance','Automatic','Statistics');

  TV shows not found / missing from library:
    → Re-paste the full list into Paste Text tab — TV support was
      added and requires a re-import to take effect
    → Shows like IT (1990) are TV miniseries on TMDB; the importer
      now searches TV as fallback after movies

  Extension import hangs / "waiting" page never redirects:
    → Timeout is 170 seconds — give it time on large lists
    → If it never resolves, check companion log for errors
    → Use the companion's Paste Text tab as alternative

  Missing packages / ImportError on startup:
    cd "C:\Users\the boy\Documents\Stremio"
    pip install -r requirements.txt

  Check requirements.txt contents:
    type "C:\Users\the boy\Documents\Stremio\requirements.txt"
